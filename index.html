Six things it actually changes

Every tweak is a real settings change on your machine вЂ” no placebo, no snake oil, nothing running in the background.

Tuned Graphics Presets

Low, Medium and High presets that write every relevant graphics setting for your target GPU in a single pass. No more guessing which of Tarkov's dozens of toggles is eating your frame time.

Stutter Fix

Reduces frame drops and input lag by tuning frame limits, V-sync and CPU affinity. These are the three settings most responsible for the rubber-banding and micro-hitches people blame on the game itself.

Cache Cleanup

Clears the shader and DirectX cache that causes stutter when a map first loads. A stale cache forces Tarkov to recompile shaders mid-raid, which is exactly when the worst hitches happen.

Config Backup

A timestamped copy of your current settings is saved before anything is touched, and restored in one click. If a preset doesn't suit your rig, you're back to exactly where you started in seconds.

Session FPS Log

Records average FPS and 1% lows per raid so you can measure each change instead of trusting your memory. Tweak, run a raid, and compare the numbers side by side.

Portable & Offline

One folder you can drop on a USB stick, run, and delete. No account, no telemetry, no background process, and no network calls вЂ” it works on a machine that's never touched the internet.

Frequently asked questions

The short version: it changes local graphics and cache settings only, and never touches the game itself.

Is this safe to use with Escape from Tarkov?

Yes. The tool only edits your local graphics configuration and clears your own shader/DirectX cache. It never writes to game files, memory or the anti-cheat process.

Does it modify game files or memory?

No. There are no DLL injections, no memory reading or writing, and no changes to any file inside the game installation. Everything it touches is a standard Windows or GPU setting that belongs to you.

Will it get me banned?

It doesn't interact with the game or its anti-cheat in any way, so there is nothing to flag. It runs while the game is closed and changes only your own settings and caches.

Does it run in the background?

No. It applies your chosen tweaks and exits. There is no resident process, no auto-start entry, and no service left behind. You run it when you want, then close it.

How do I restore my old settings?

Before making any change, the optimizer saves a timestamped backup of your current settings. If a preset doesn't feel right, open the backup tab and restore it in one click.

What does the FPS log measure?

Per raid it records your average FPS and your 1% lows вЂ” the frames that drop during heavy firefights. Comparing these numbers is the only reliable way to know if a tweak actually helped.
